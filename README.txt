GHE Extra Stats
===============

Adds Shield, Retaliate and Attack (each stacks to 20) to the right-click
condition menu on figures in Frosthaven Enhanced (also works in Gloomhaven
Enhanced). Replaces the old "Extra Stats Modifiers - TTS Enhanced" workshop
plugin, which only works with the outdated TTS Enhanced v1.2 mod.

Install
-------
1. Run ./install.sh
   It copies the saved object into Tabletop Simulator's "Saves/Saved Objects"
   folder (native, Flatpak, or Proton install). If it can't find the folder,
   copy "GHE Extra Stats.json" and "GHE Extra Stats.png" there by hand.

2. In TTS, load the Frosthaven game. If the old Extra Stats plugin pieces are on
   the table (Shield / Retaliate / Attack bags, "Protector of the UI" knight),
   delete them.

3. Objects > Saved Objects > GHE Extra Stats. Place the token anywhere on the
   table and save the game.

4. Reload the save. Right-clicking a figure should now show Shield, Retaliate
   and Attack in the condition menu.

The token must stay on the table in each save that should have these three.
